# 결과 그리드 마우스 범위 선택 및 복사

## 목표

쿼리 결과 그리드에서 마우스 드래그로 셀 직사각형, 연속 행, 연속 열을 선택하고 `⌘/Ctrl+C`로 DataGrip처럼 TSV 복사한다. 전체 행 범위도 선택할 수 있으며 가상 스크롤을 넘어 드래그할 때 자동으로 따라간다.

## 설계

- 기존 클릭/Shift+클릭 및 키보드 탐색을 유지하면서 포인터 드래그 중 셀 선택 끝점을 갱신한다.
- 셀 드래그는 직사각형 범위를 선택한다. 행 번호 드래그는 전체 열을 포함해 행 범위를 선택한다.
- Shift를 누른 채 열 헤더를 드래그하면 전체 행을 포함한 연속 열을 선택한다. 일반 헤더 드래그의 기존 열 재배치 동작을 유지한다.
- 선택 좌표는 현재 화면의 열 순서를 따르며, 고정·재정렬된 열이 있어도 복사 결과가 화면 순서와 일치한다.
- 그리드에 포커스를 주어 마우스 선택 후 `⌘/Ctrl+C`가 선택 영역을 TSV로 복사하게 한다. 드래그 시 브라우저 텍스트 선택은 막는다.
- 가상 행 바깥으로 드래그하면 그리드가 가장자리에서 자동 스크롤하고 선택을 계속 확장한다.

## 구현 및 검증

1. 격리된 임시 SQLite DB를 사용하는 Playwright E2E를 먼저 추가해 셀, 행, 열, 전체 범위의 드래그 선택과 클립보드 TSV를 검증한다.
2. ResultGrid의 선택 좌표 및 포인터 드래그 처리를 구현하고 CSS 선택 표시를 확인한다.
3. renderer/desktop 빌드 후 격리 Electron E2E를 실행한다.
4. 실제 앱에서 결과 그리드를 조작하고 복사한 값을 확인한다. 검증 데이터와 프로필은 임시 경로에서 만들고 제거한다.

커밋, 푸시, PR, 머지는 별도 요청이 있을 때 수행한다.

- 기존 결과 열 너비 조절 E2E 통과.
