# 쿼리 세션 탭 우클릭 닫기 메뉴

## 설계

- QueryEditor의 쿼리 탭 우클릭 메뉴: 현재 탭, 다른 탭, 왼쪽 탭, 오른쪽 탭, 모든 탭 닫기.
- 우클릭한 탭을 기준으로 범위를 계산하며 활성 탭을 불필요하게 바꾸지 않는다.
- 닫을 대상이 없으면 항목을 비활성화한다. 외부 클릭, Escape, 스크롤/창 크기 변경 시 메뉴를 닫고 화면 경계 안에 표시한다.
- 탭 범위 및 활성 탭 선택을 renderer 순수 모듈로 분리하고 RED → GREEN으로 검증한다.
- 마지막 탭까지 닫으면 새 빈 Query 1 탭을 만든다. 쿼리/결과/세션은 새 탭에 복사하지 않는다.
- 기존 X 버튼과 메뉴를 공통 종료 경로로 연결한다. 미커밋 트랜잭션은 한 번의 롤백 확인을 거치고, 엔진 세션 종료에 실패하면 해당 탭을 유지한다.
- 실제 앱에서 실행 중 쿼리 취소의 간헐적 지연이 재현되어, 실행 중인 탭을 포함한 닫기 범위는 비활성화한다. 실행 탭을 유지하며 다른 대기 탭은 일괄 닫을 수 있다. 기존 쿼리 취소 transport는 변경하지 않는다.
- 닫기 처리 중 중복 종료 요청을 막고 최신 탭 상태를 사용한다. 닫기 취소 시 기존 탭/대기 실행 상태를 유지한다.

## 검증

1. 범위/경계/활성 탭 선택 단위 테스트 실패 확인 후 구현 및 통과.
2. renderer 단위 테스트 및 renderer/desktop 빌드.
3. 격리된 Electron + engine + 임시 SQLite DB로 Playwright E2E: 메뉴 범위, 비활성 상태, 메뉴 닫기, 탭 선택 및 내용 유지, 모두 닫기 후 재실행, 저장/재접속, 미커밋 취소/롤백, 실행 중 탭 보호 및 다른 탭 일괄 닫기.
4. 실제 메뉴 스크린샷 확인. 테스트 DB/프로필은 임시 경로에서 생성 및 삭제.

커밋/푸시/머지는 별도 요청이 있을 때 수행한다.

## 검증 결과

- renderer 단위 테스트 455개 통과(닫기 범위/활성 탭/실행 탭 보호 13개 포함).
- renderer 및 desktop 빌드, 신규 순수 모듈/메뉴 ESLint, diff 공백 검사 통과.
- 실제 Electron E2E 8개 통과: query-tab-context-menu, query-tab-persistence, query-transactions, connection-session-lifecycle.
- 메뉴 화면을 캡처하고 직접 확인했다. 검증용 SQLite DB와 격리 프로필을 삭제하고 테스트에서 남은 고아 엔진도 정리했다.
- 실행 중 탭 닫기 시 기존 취소 경로의 간헐적 지연을 확인했다. 실행 중 탭을 보호하는 최종 동작을 실제 앱에서 검증했으며, 취소 transport 수정은 포함하지 않았다.
