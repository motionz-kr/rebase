# 세션 관리 및 쿼리탭 복원 계획

## 목표

연결 프로필별 쿼리탭을 안전하게 복원하고, 현재 연결에서 사용하는 탭(client)과 수동 트랜잭션 세션을 DataGrip Services처럼 확인·관리한다.

## 범위

- 쿼리탭의 SQL, 이름, 스키마, 탭별 Read/Write, Auto/Manual 설정을 프로필별 로컬 저장소에 보관한다.
- 재연결 또는 앱 재시작 시 저장된 탭을 복원한다.
- 결과 행, 실행 중 상태, 쿼리 ID, 실제 DB 세션 ID는 저장하지 않는다.
- 세션 관리 모달에서 탭별 연결 상태, 권한, 트랜잭션 상태, 세션 ID를 표시한다.
- 세션 관리 화면에서 탭 전환, Commit, Rollback, 수동 세션 종료, 실행 중 쿼리 취소를 제공한다.
- 세션 종료는 미커밋 변경을 자동 Commit하지 않고 Rollback하는 기존 정책을 따른다.

## 비범위

- 여러 쿼리탭의 세션 공유 모드
- 운영 DB에 저장되는 쿼리탭 동기화
- 실제 DB 세션 ID의 재연결 복원

## 구현 순서

1. 쿼리탭 영속화 직렬화/검증 순수 테스트를 먼저 추가한다.
2. QueryEditor에 프로필별 복원·저장과 세션 관리 UI를 연결한다.
3. 세션 관리 액션을 기존 탭별 트랜잭션/취소 핸들러에 연결한다.
4. SQLite Electron E2E에서 탭 복원과 세션 관리 화면을 실제 조작으로 검증한다.
5. 전체 renderer 테스트 및 빌드를 실행한다.

## 완료 기준

- 연결을 끊었다 다시 연결해도 같은 프로필의 쿼리탭과 SQL이 복원된다.
- 다른 프로필의 탭은 서로 섞이지 않는다.
- 세션 관리 화면에서 탭별 상태를 확인하고 현재 탭을 바꿀 수 있다.
- Commit/Rollback/세션 종료/실행 취소가 기존 동작과 동일하게 안전하게 수행된다.
