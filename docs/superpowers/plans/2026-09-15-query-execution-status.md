# SQL 문장별 실행 상태 표시 계획

## 목표

쿼리 편집기에서 여러 SQL 문장을 이어 실행할 때 각 문장의 실행 중·성공·실패·건너뜀 상태를 코드 영역 안에서 즉시 확인할 수 있도록 한다.

## 범위

- SQL 문장별 소스 범위를 계산하고 실행 상태를 추적한다.
- Monaco 편집기 여백에 상태 아이콘과 라인 표시를 렌더링한다.
- 상태에 대한 hover 설명을 제공한다.
- 쿼리 탭별 스키마 표시와 함께 회귀 테스트 및 실제 Electron E2E 흐름을 유지한다.

## 검증

- 문장 분리·범위 계산 단위 테스트
- renderer 테스트, lint, build
- desktop build
- 실제 Electron에서 다중 문장 성공·실패·건너뜀 상태를 확인하는 Playwright E2E
