# 쿼리탭 스키마 정보 표시 계획

## 목표

여러 스키마를 오가며 쿼리탭을 열어도 각 탭이 어느 스키마를 대상으로 하는지 즉시 구분할 수 있도록 한다.

## 범위

- SQL 쿼리탭 상태에 데이터베이스/스키마 컨텍스트를 저장한다.
- 스키마 탐색기에서 쿼리 입력 또는 테이블 최근 조회를 열 때 현재 탭의 컨텍스트를 갱신한다.
- 새 탭은 생성 시점의 활성 스키마를 상속한다.
- 각 탭 라벨에 스키마 이름을 간단히 표시한다.
- 실행, 자동완성, 편집 테이블, 위험 쿼리 분석이 활성 탭의 컨텍스트를 사용하도록 유지한다.

## 검증

- 탭 라벨 생성/표시 순수 로직 테스트를 먼저 추가한다.
- Renderer 단위 테스트와 빌드를 실행한다.
- 격리된 SQLite fixture를 사용하는 Desktop E2E에서 스키마 이동 후 탭별 라벨과 실행 대상을 확인한다.
- 변경 후 실제 Electron 앱을 Playwright로 조작해 검증한다.
