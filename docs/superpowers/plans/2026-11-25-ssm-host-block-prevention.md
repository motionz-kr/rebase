# SSM 연결 오류 재발 방지 (#238)

- SSM 플러그인 출력으로 터널 준비를 판단하고, 로컬 포트에 TCP 연결을 열었다 닫는 준비 확인을 제거한다. 실제 DB 드라이버는 로컬 소켓 연결이 거절된 경우에만 짧게 재시도한다.
- 살아 있는 프로필별 터널을 재사용한다. 같은 AWS 경로의 새 터널은 엔진당 최근 1분에 최대 5개로 제한하고 연속 시작 실패에는 지수 백오프를 적용한다. 임시 연결 테스트 종료 후에도 시작 기록을 보존한다.
- MySQL 1129 수신 시 경유 IP 차단과 관리자 조치를 안내한다. 같은 SSM DB 경로의 자동 연결 요청을 1분 동안 중단하고 이후 실제 요청에서 접속할 수 있게 한다.
- 로컬 가짜 SSM 및 MySQL로 준비 확인 접속 0건, 재시작 제한, 1129 재접속 억제, 정상 접속과 명시적 재실행을 검증한다.
